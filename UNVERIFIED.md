# Unverified claims — the launch checklist for /combination-cream

Every factual claim on the ad landing page is wrapped in the `<Unverified>`
component (`src/components/landing/Unverified.tsx`): statistics, the review
count and rating, the price, the delivery estimate, guarantee terms,
certifications, and every statement about what Estrada does clinically. The
figures are plausible-shaped placeholders so the layout can be judged. None
of them is real.

**What the component does**

| Build                                          | Behaviour                                  |
| ---------------------------------------------- | ------------------------------------------ |
| `npm run dev`                                  | Yellow highlight, tooltip names the claim  |
| Vercel Preview deployment                      | Yellow highlight (so previews can be shared) |
| `ALLOW_UNVERIFIED=1 npm run build`             | Yellow highlight (to check a build locally) |
| Any other production build, incl. Vercel Production | **Build fails** naming the claim       |

The page is prerendered, so the throw happens during `next build`; nothing
with a placeholder can reach production.

**To clear an item:** replace the placeholder text in `src/content/landing.ts`
with the verified figure and remove the `<Unverified>` wrapper in the section
component (or delete the `verify` field where the content file drives it).
Then re-run `node scripts/unverified-list.mjs --update` to refresh the table
below, and `npm run launch-check`, which also counts these marks.

**Copy that is deliberately not marked** (it makes no factual claim or is
client-supplied): headlines, "Prescription treatment", the cash-pay FAQ
answer, the "who prescribes" and "who fills" FAQ answers (from the site FAQ),
and the footer disclosures. `[PHARMACY_NAME_PLACEHOLDER]` remains a separate
marker tracked in COMPLIANCE_NOTES.md.

**Also placeholders, outside the yellow marks:** every image (see
`public/images/landing/README.md`), and the testimonial portraits, which must
match the people quoted.
